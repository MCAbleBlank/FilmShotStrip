
## 输入与输出

| 参数 | 默认 | 说明 |
|---|---|---|
| `video` | 必填 | 输入视频文件 |
| `-o, --output` | `<片源名>_strip.jpg` | 输出路径；扩展名 `.jpg` / `.png` / `.webp`，无扩展名按 `.jpg`；也可只给前缀 |
| `--height` | 1080 / 1000 | 画面高度；`--px-per-shot > 0` 时默认 1000 |
| `--quality` | 92 | JPEG 质量 |
| `--preview-width` | 2600 | 预览图最大宽度 |
| `--preview-height` | 0 | 预览图最大高度；0 = 按宽度等比 |
| `--no-preview` | 关 | 不生成预览图 |
| `--no-json` | 关 | 不写分镜清单（不影响缓存） |
| `--shots-dir` | `out` | 分镜清单输出目录 |

## 排版

| 参数 | 默认 | 说明 |
|---|---|---|
| `--px-per-second` | `auto` | 每秒时间占多少像素；`auto` 由 `--target-width` 反推 |
| `--target-width` | 14000 | auto 模式的目标总宽 |
| `--max-width` | 24000 | 单张图最大宽度，超出自动分段；实际上限 64900 |
| `--min-shot-px` | 2 | 每个分镜最小像素宽度（固定像素/等宽模式除外） |
| `--px-per-shot` | 0 | 每个取色帧固定像素宽；0 关闭 |
| `--shot-samples` | `fml` | `fml` 首/中/末帧各一列；`avg` 不拆帧，每镜占 N 像素（N=1 时取整镜平均色）；仅在 `--px-per-shot > 0` 时生效 |
| `--equal-width` | 关 | 每个分镜等宽，总宽取 `--target-width` |
| `--per-second [PX]` | 关 | 每秒 1 帧，每帧 PX 像素（默认 1）；跳过镜头检测 |

## 镜头检测

| 参数 | 默认 | 说明 |
|---|---|---|
| `--method` | `auto` | `auto` / `scenedetect` / `scdet` / `uniform` |
| `--detector` | `content` | PySceneDetect 的 `content` 或 `adaptive` |
| `--scene-threshold` | 0.35 | 0~1，越小切得越碎；常用 0.25~0.5 |
| `--shot-length` | 3.0 | `--method uniform` 时每个分镜的秒数 |
| `--min-shot` | 0.6 | 短于该秒数的分镜并入相邻镜头 |
| `--max-shot` | 0 | 长于该秒数的镜头平均切开；0 关闭 |
| `--merge-similar` | 0 | 合并代表色相近的相邻分镜；0 关闭，建议 6~12 |

## 采样与渲染

| 参数 | 默认 | 说明 |
|---|---|---|
| `--style` | `gradient` | `gradient` / `dominant` / `frame` |
| `--sample-fps` | 0 | 采样帧率；0 = 自动（按片长和最短镜头） |
| `--sample-width` | 0 | 采样宽度；0 = 自动（gradient/dominant 160，frame 480） |
| `--blur` | 0.7 | 整图高斯柔化半径；0 关闭；每帧 1px / 每秒 1px 时自动关闭 |
| `--median` | 0 | 中值滤波尺寸，3 或 5；0 关闭 |
| `--ruler` / `--no-ruler` | 开 | 底部时间刻度 |

## 缓存与日志

| 参数 | 默认 | 说明 |
|---|---|---|
| `--cache-dir` | `out/.cache` | 分镜/色带缓存目录 |
| `--no-cache` | 关 | 不读也不写缓存（同时跳过片源哈希） |
| `--refresh-shots` | 关 | 忽略已有缓存，强制重新检测 |
| `-q, --quiet` | 关 | 减少日志 |
| `--no-progress` | 关 | 不显示进度条（保留日志） |
| `-V, --version` | — | 打印版本 |
